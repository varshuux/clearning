QUESTION 1

Q1.Write a program in which a pointer points to an array and insert value from user through pointer.

CODE

#include <stdio.h>
void main()
{
	int a[5], i;
	int *p;

	p = a;

	for(i = 1; i <= 5; i++)
	{
		printf("Enter %d value: ", i);
		scanf("%d", p);
		p++;
	}

	p = a;

	printf("\nArray values: ");
	for(i = 1; i <= 5; i++)
	{
		printf("%d ", *p);
		p++;
	}
}

OUTPUT

C:\TURBOC3\BIN>TC

Enter 1 value: 76
Enter 2 value: 90
Enter 3 value: 21
Enter 4 value: 34
Enter 5 value: 54

Array values: 76 90 21 34 54

QUESTION 2

Q2. Write a program to input and display the elements of a 2D array of size 2 x 3 using a pointer.

CODE

#include <stdio.h>
void main()
{
	int a[2][3], i, j;
	int *p;

	p = a;

	for(i = 1; i <= 6; i++)
	{
		printf("Enter %d value: ", i);
		scanf("%d", p);
		p++;
	}

	p = a;

	printf("\nArray values: \n");
	for(i = 0; i < 2; i++)
	{
		for(j = 0; j < 3; j++)
		{
			printf("%d ",*p);
			p++;
		}
		printf("\n");
	}
}

OUTPUT

C:\TURBOC3\BIN>TC

Enter 1 value: 66
Enter 2 value: 77
Enter 3 value: 00
Enter 4 value: 21
Enter 5 value: 43
Enter 6 value: 54

Array values: 
66 77 00 
21 43 54
