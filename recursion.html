QUESTION 1

Q1.Write a program to print numbers from 1 to 5 using recursion.

CODE

#include <stdio.h>
              void ptr(int n)
{
	if(n <= 5)
	{
		printf("\n%d ",n);
		ptr(n + 1);
	}
}
void main()
{
	ptr(1);
}

QUESTION 2

Q2.Write a program to print numbers from 1 to 5 using recursion and a global variable.

CODE

#include <stdio.h>
             int n = 1;

void ptr()
{
	if(n <= 5)
	{
		printf("%d ", n);
		n++;
		ptr();	
	}
}
void main()
{
	ptr();
}

OUTPUT

C:\TURBOC3\BIN>TC
              1
              2
              3
              4
              5
